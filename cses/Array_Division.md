# CSES - Array Division

## 핵심 요약

양수 배열을 정확히 `K`개의 비어 있지 않은 연속 구간으로 나눌 때, 구간 합의 최댓값을 최소화한다. 합의 상한 `x`를 고정하면 왼쪽부터 가능한 한 같은 구간에 넣는 그리디로 필요한 구간 수를 구할 수 있다.

## 접근과 불변식

현재 구간의 합을 `acc`에 둔다. 다음 원소까지 넣으면 상한을 넘을 때 새 구간을 시작한다. 원소 하나가 `x`보다 크면 불가능하다. 양수이므로 상한을 넘기 전까지 합치는 선택이 필요한 구간 수를 늘리지 않는다.

필요한 구간이 `K`개 이하면 가능하다. 부족한 구간 수는 기존 구간을 더 나누어 맞출 수 있고, 합의 최댓값은 증가하지 않는다. 가능한 상한 이상은 모두 가능하므로 최소 참을 탐색한다. 현재 코드는 아래쪽 중간값과 `hi = mid`, `lo = mid + 1`을 사용한다.

시간은 `O(N log S)`이며 `S`는 원소 합이다. `values + [0]` 복사와 입력을 포함한 공간은 `O(N)`이다. 끝의 0은 현재 판정에서 불필요하지만 결과를 바꾸지는 않는다.

## 실패와 도움

사용자가 판정과 이분 탐색을 구현했다. 에이전트가 구간 안에 들어가는 원소를 `acc`에 더하는 누락과, 원소 하나가 상한보다 큰 경우의 처리를 수정·설명했다. 최소 참 탐색을 이전 최대 참 문제와 비교했다.

## 확인한 입력

```text
3 3
5 100 2
```

기대 출력과 현재 실제 출력은 `100`이다. 구간 수만 맞더라도 원소 100을 더 작은 상한 안에 넣을 수는 없다.
