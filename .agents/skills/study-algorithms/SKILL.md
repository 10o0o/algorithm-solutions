# 알고리즘 학습 이어가기

[현재 위치](../../../STATE.md), [로드맵](../../../ROADMAP.md), 이번 요청의 문제·사용자 코드·설명을 읽는다.
로드맵은 우선순위이며, 이미 아는 기초를 처음부터 다시 수강시키는 체크리스트가 아니다.
사용자가 지정한 주제가 있으면 그 범위를 우선한다. 저장된 STATE와 현재 대화가 다르면
현재 확인한 사실을 설명하고 재개 지점을 맞춘다.

## 풀이와 피드백

- 먼저 현재 접근과 막힌 지점을 확인한다. 이미 제출한 코드나 설명을 다시 처음부터 요구하지 않는다.
- 필요한 만큼 단계적으로 힌트를 제공하고, 사용자가 직접 구현·실행·설명하도록 돕는다.
  연습 중 모범풀이를 명시적으로 요청하면 제공하고 도움받은 범위를 구분한다.
- 리뷰는 실제 코드와 관찰한 출력에 근거한다. 검증이 필요하면 해당 문제의 샘플·반례만
  격리해 실행하고, 풀이 수정은 사용자가 요청한 범위에서 수행한다.
- 실전 대회가 진행 중이면 풀이·디버깅 도움은 종료 후 복기로 돌린다.
  기준선 측정용 virtual도 제한 시간이 끝난 뒤 리뷰한다.
- 일반 설명, 힌트, `이해했어`는 기록 요청이 아니다. 파일이나 진도를 자동 갱신하지 않는다.

## 마무리와 저장 요청

`오늘 학습 종료`에는 진행을 멈추고 현재 남은 질문과 다음 독립 행동을 짧게 제안한다.
이 말만으로 노트나 STATE를 쓰지 않는다. `STATE 반영해` 또는 동등한 명시적 요청이면
확인된 현재 범위와 다음 행동만 STATE에 저장하고 변경 내용을 보고한다.
이미 합의된 재개 내용에 대해 다시 승인을 요구하지 않는다.

`개념 정리해줘`, `문제 복기해줘`, `이번 대회 복기해줘`는 각각
[지식 정리](../record-algorithm-knowledge/SKILL.md),
[문제 복기](../review-algorithm-problem/SKILL.md),
[대회 복기](../review-algorithm-contest/SKILL.md)로 연결한다.
`정리해줘`만 있으면 현재 대상이 명확할 때 그 범위만 저장하고, 대상이 불명확할 때만 묻는다.

샘플 통과나 설명을 들었다는 사실을 온라인 AC·독립 해결·숙달로 바꾸지 않는다.
이 학습 스킬은 커밋·push·배포를 자동 수행하지 않는다.
