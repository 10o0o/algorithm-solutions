# 대회 복기와 다음 연습

[작성 규칙](../../../contests/README.md)과 [대회 템플릿](../../../contests/template.md)을 읽는다.
현재 대화에서 확인한 대회·virtual 정보, 실제 코드·기존 복기·제출 결과를 사용한다.
대회나 참가 범위가 불명확하면 필요한 정보만 묻는다. 실전·측정용 virtual이 진행 중이면 풀이·디버깅을 제공하지 않고 제한 시간 종료 후 복기한다.

## 대회 기록

`contests/<대회-slug>.md`에 `title`, `updated`, `tags`, 실제 대회의 HTTPS `url`을 둔다.
같은 회차는 기존 문서에 병합하고, 다른 날짜의 virtual 재참가처럼 실제로 별도인 회차만
구분되는 이름을 사용한다. 문서 날짜를 과거 참가일로 오인하지 않도록 실제 참가일은 확인된 때만 쓴다.

실제로 사용한 시간과 접근 순서, 해결·미해결 문제, 확인된 WA/TLE 원인, 도움 사용을 구분한다.
정보가 없는 칸을 예측으로 채우지 않는다. 기록 요청만으로 모든 문제를 풀거나 해설을 작성하지 않는다.

## 회차와 결과의 분류

목표·판정 조건은 [로드맵의 목표와 측정](../../../ROADMAP.md#목표와-측정)을 따른다. 실전 올솔, 미견 virtual 올솔, 종료 후 업솔빙 전체 AC, 기출 재풀이 올솔을 구분한다. 각 조건의 전 문제 AC를 확인하기 전에는 올솔로 확정하지 않는다. 실전 `5/7` 뒤 업솔빙 `7/7`이면 두 결과를 함께 남기며 실전 결과를 소급 변경하지 않는다.

실제 회차·참가 일시·전체 문제 수·공식 제한 시간·실제 측정 시간·문제/해설 사전 노출·도움·판정 출처를 확인한다. 조사한 한 ABC의 100분·7문제를 다른 회차에 자동 적용하지 않는다. 이미 본 세트로 진행한 virtual은 기출 재풀이, 도움 받은 virtual은 일반 연습으로 구분한다. 도움·노출 미확인은 독립 측정 확정을 보류하되 확인된 일반 연습 결과를 버리지 않는다.

시간은 실제 관찰/사용자 보고·근사 여부 또는 미측정으로 남긴다. 대회 시작부터 AC 제출까지의 누적 시각을 문제별 순수 사고·구현 시간으로 쓰지 않는다. 공식 제출 직접 확인·사용자 보고·비공식 제출 자료를 구분하고 샘플 통과를 온라인 AC로 바꾸지 않는다. 공식 rating은 출처·확인일과 함께 기록하며 최초 도달과 현재 rating, 한 번의 performance를 구분한다.

요청한 본문에는 문제별 실제 코드/버전과 작성자·힌트/AI 제공/수정의 시점·영향, 실행자·환경·입력 범위·예상값/실제 출력·미실행을 필요한 만큼 남긴다. 같은 날 재구현은 추가 도움·자료 사용과 실제 결과, 다른 날 재현은 별도 날짜의 자료·핵심 도움 없는 직접 구현·검증, 새 문제 적용은 다른 대상의 노출·접근 선택·정당성·구현·도움을 구분한다. 미확인 과거 도움·판정을 추정하거나 대회 복기 요청으로 별도 학습 기록 전체를 자동 생성하지 않는다.

## 다음 연습과 연결

다음 업솔빙 대상은 반복된 약점과 당시 접근을 기준으로 소수만 고르고, 다음 대회에서 바꿀
행동을 한두 가지로 좁힌다. 공식 레이팅을 다른 플랫폼 등급이나 문제 난이도로 환산하지 않는다.

이미 있는 문제·개념 노트를 상대 링크로 연결한다. 사용자가 문제별 복기나 개념 정리까지
요청했다면 해당 기록 스킬을 함께 적용하되, 생성하지 않은 문서를 연결하지 않는다.
raw HTML이나 템플릿 안내 주석은 남기지 않는다. 새 사실이 없으면 중복 기록을 만들지 않는다.

## 검증과 보고

```bash
uv run --frozen python scripts/validate_notes.py contests/<대회-slug>.md
git diff --check
```

저장한 경로, 확인된 결과, 다음 행동을 보고한다. STATE 변경은 현재 요청 또는 현재 대화에서
확인된 기존 위임 범위에서 수행하고, 권한이 없으면 넣을 내용만 제안한다. 대회 복기만으로
풀이·CPH 데이터 변경·커밋·push·배포 권한을 확대하지 않는다. 종료와 원격 확인은
[학습 스킬](../study-algorithms/SKILL.md#종료와-다음-세션)과
[원격 동기화 규칙](../../../AGENTS.md#저장과-원격-동기화)을 따른다.
