# 대회 복기와 다음 연습

[작성 규칙](../../../contests/README.md)과 [대회 템플릿](../../../contests/template.md)을 읽는다.
현재 대화에서 확인한 대회·virtual 정보, 실제 코드·기존 복기·제출 결과를 사용한다.
대회나 참가 범위가 불명확하면 필요한 정보만 묻는다. 실전 대회가 진행 중이면 종료 후 진행한다.

## 대회 기록

`contests/<대회-slug>.md`에 `title`, `updated`, `tags`, 실제 대회의 HTTPS `url`을 둔다.
같은 회차는 기존 문서에 병합하고, 다른 날짜의 virtual 재참가처럼 실제로 별도인 회차만
구분되는 이름을 사용한다. 문서 날짜를 과거 참가일로 오인하지 않도록 실제 참가일은 확인된 때만 쓴다.

실제로 사용한 시간과 접근 순서, 해결·미해결 문제, 확인된 WA/TLE 원인, 도움 사용을 구분한다.
정보가 없는 칸을 예측으로 채우지 않는다. 기록 요청만으로 모든 문제를 풀거나 해설을 작성하지 않는다.
다음 업솔빙 대상은 반복된 약점과 당시 접근을 기준으로 소수만 고르고, 다음 대회에서 바꿀
행동을 한두 가지로 좁힌다. 공식 레이팅을 다른 플랫폼 등급이나 문제 난이도로 환산하지 않는다.

이미 있는 문제·개념 노트를 상대 링크로 연결한다. 사용자가 문제별 복기나 개념 정리까지
요청했다면 해당 기록 스킬을 함께 적용하되, 생성하지 않은 문서를 연결하지 않는다.
raw HTML이나 템플릿 안내 주석은 남기지 않는다. 새 사실이 없으면 중복 기록을 만들지 않는다.

## 검증과 보고

```bash
uv run --frozen python scripts/validate_notes.py contests/<대회-slug>.md
git diff --check
```

저장한 경로, 확인된 결과, 다음 행동을 보고한다. 다음 재개 위치가 달라졌다면 STATE에 넣을
내용을 제안하고 `STATE 반영해` 요청 때 저장한다. 대회 복기만으로 풀이·CPH 데이터를
변경하거나 커밋·push·배포하지 않는다.
