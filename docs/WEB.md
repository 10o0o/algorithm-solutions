# 학습 사이트 종료와 복구

2026-10-24 사용자 요청으로 별도 학습 사이트를 제거했다. 학습은 저장소의 원본 Markdown과
풀이 코드에서 계속하며 STATE·ROADMAP·개념/문제/대회 노트는 삭제하지 않는다.

- 제거: `web/`의 Astro 화면·검색·사이트 테스트·Node 의존성/설정, 웹 빌드와 Pages 배포 jobs.
- 유지: Python 검사, 노트 검증, lockfile 검사, 플랫폼 풀이, 학습 자료와 현재 진도.
- `main` push·수동 workflow 실행은 일반 검사만 수행한다. 사이트를 다시 게시하지 않는다.
- 원격 Pages 서비스 비게시화는 소스 제거와 별도 작업이다. 소스 변경만으로 기존 URL의
  비게시화를 확인했다고 보고하지 않는다.

## 이전 사이트 복구

마지막 제거 전 소스는 [c7ab78d의 web 디렉터리](https://github.com/10o0o/algorithm-solutions/tree/c7ab78d244bb310627b6a841e0caada0bda20f07/web)에 남아 있다.
기존 [검증 기록](VALIDATION.md)은 당시 동작의 역사 자료다. 그 안의 웹 명령은 현행 지침이 아니다.
필요하면 이 커밋의 웹 파일을 별도 작업 브랜치로 복원할 수 있다. 복구를 위해 현재 학습 파일을
reset하거나 과거 커밋으로 전체 저장소를 되돌리지 않는다. 배포 workflow·Pages 게시를 다시 켜는
작업은 별도의 명시 요청이 필요하다.
