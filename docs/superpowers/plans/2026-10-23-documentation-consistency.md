# 수업 운영 문서·스킬 정합성 개선 구현 계획

> **실행 담당·필수 하위 스킬:** `superpowers:executing-plans`로 현재 세션에서 작업별로 구현한다. 기존에 선택한 Native 방식을 유지한다. 아래 체크박스는 실제 구현·검증 후에만 표시한다.

**실행 상태:** 2026-10-23 사용자 요청으로 네 작업을 로컬 반영·검증했다. 별도 전체 변경 검토에서 실질적 결함은 없었고, 동시 변경 대조 후 공유 작업 위치에 반영해 내용을 확인했다. 실제 결과는 아래에 둔다.

**Goal:** 개선된 수업 방식과 충돌하는 안내와 과거 자료의 오해를 바로잡고, 필요한 경우에만 기록 스킬의 행동을 보완한다.

**Architecture:** AGENTS는 공통 보존·검증 경계, 학습 스킬은 수업 운영, ROADMAP은 목표·예산, STATE는 재개 위치를 맡는다. 안내서는 이 기준을 연결하고 과거 문서에는 시점 안내를 붙인다. 새 학습 시스템·검사기·필수 기록 양식은 만들지 않는다.

**Tech Stack:** 기존 Markdown·YAML, uv·CPython 3.12, `markdown-it-py`·PyYAML. 공개 문제 노트 검증에는 기존 Astro·Vitest·Playwright를 사용한다. 웹 요구 버전은 Node `>=22.12.0`, npm `>=9.6.5`다. 의존성을 추가하지 않는다.

**Spec:** [전수 점검 보고서](../../DOCUMENTATION_AUDIT.md)의 F01–F09·R01–R02와 파일별 판정. 채택된 수업 방식은 [TEACHING_DESIGN](../../TEACHING_DESIGN.md), 세부 운영은 [학습 스킬](../../../.agents/skills/study-algorithms/SKILL.md)을 함께 읽는다. 보고서의 수정안은 이 계획 검토 후 적용한다.

## 공통 제약 — Global Constraints

- [수업 개선 설계](../../TEACHING_DESIGN.md): “사용자 학습은 계속 중단 상태이며, 실제 학습 효과는 아직 관찰하지 않았다.” 이번 작업을 학습 재개·숙달 확인으로 기록하지 않는다.
- 같은 설계: “혼합 연습에서도 원문 자체의 표현·제목을 임의로 바꾸지 않는다.” 충분한 현재 코드·설명·실행을 다시 시험하지 않는다.
- 같은 설계: “모든 문제의 즉시 재구현을 요구하지 않는다.” 다음 이동과 요청형 모범 코드에 강제 재시험을 붙이지 않는다.
- 같은 설계: “혼합·재현·대회는 총 주 5–7시간 안의 활동이다.” ROADMAP의 기존 목표·주제·여섯 예산표를 그대로 보존한다.
- [AGENTS](../../../AGENTS.md): “학습 기록 저장, 사용자 풀이 수정, 커밋·push, 온라인 제출·배포는 별도 범위입니다.” 이 계획은 새 커밋·push·Pages 갱신을 수행하는 지시가 아니다.
- 같은 지침: “Linux/WSL, uv, CPython 3.12가 기본 환경입니다.” 사용자 코드·LeetCode API·루트 `main.py`·`ex.in`·CPH 반례·기존 경로를 보존한다.
- [퇴역 안내](../../../.specify/README.md): “이 자료의 과거 실행 명령과 모델·단계 승인 정책을 현재 지시로 사용하지 않는다.” 퇴역 자산·미비준 헌법을 수정·실행하지 않는다.
- 확정 수정은 기존 18개 파일이다. 조건부 기록 스킬 2개는 Task 3의 관찰 근거가 있을 때만 수정한다. 그 밖의 58개와 소스·설정·의존성은 유지한다.
- 문장 일치만 확인하는 회귀 테스트를 만들지 않는다. 링크·메타데이터·수학적 예제는 실제 검사하고, 스킬 행동은 실제 응답으로 확인한다. 가상 평가를 사용자 학습 이력에 쓰지 않는다.

Task 1은 현행 진입 안내, Task 2는 과거 자료의 경계, Task 3은 필요한 기록 스킬 보완, Task 4는 공개 복기의 모호성 수정과 최종 대조를 맡는다. 각 작업은 별도 diff와 검증 결과로 검토할 수 있다. 같은 파일의 수정자는 실행 담당 한 명이다.

실행 전 `using-git-worktrees`로 현재 작업·사용자 변경을 보존하는 작업 위치를 확인한다. 이 계획과 보고서의 미커밋 내용을 잃지 않게 포함하고, 사용자 풀이를 격리 작업 위치로 옮기거나 초기화하지 않는다. 검토된 문서 수정 범위를 작업마다 다시 승인받지 않는다. 커밋·게시 권한은 공통 제약을 따른다.
