## 문제별 검토

### A·B: 현재 구현 유지

A는 `o` 개수의 홀짝, B는 행 5개·열 5개·대각선 2개의 빈칸 수를 조사한다. 제출 코드의 접근에 수정이 필요한 점은 발견하지 못했다. 짧게 다시 쓰는 것을 이번 과제로 삼지 않는다.

### C: 좌표 압축·누적합을 이분 탐색으로 줄이기

사용자는 C를 어렵게 푼 것 같다고 보고했다. 실제 제출은 각 점의 좌표와 모든 질의의 양 끝점을 함께 정렬하고, 좌표→인덱스 사전과 누적합으로 답한다. 행·열을 독립적으로 다룬 관찰은 정확하다. 중복 좌표가 남아 있어도 사전이 마지막 인덱스로 대응시키고 해당 위치에 개수를 모으므로 현재 계산은 성립한다.

하지만 점의 추가·삭제가 없고 필요한 것은 구간 안의 개수뿐이다. 점마다 행 번호 하나와 열 번호 하나를 저장한 배열을 각각 정렬하면 된다. 질의 끝점까지 저장하거나 좌표 사전·누적합을 만들 필요가 없다. [공식 C 해설](https://atcoder.jp/contests/abc482/editorial/28016)도 이 접근을 사용한다.

```python
from bisect import bisect_left, bisect_right

# rows와 cols는 점의 좌표를 중복도 포함해 정렬한 배열
arr = rows if flag == 1 else cols
answer = bisect_right(arr, b) - bisect_left(arr, a)
```

`bisect_right(arr,b)`는 `b` 이하의 개수, `bisect_left(arr,a)`는 `a` 미만의 개수다. 차이는 닫힌 구간 `[a,b]`의 개수다. 예를 들어 `[1,2,2,4,5]`에서 `[2,4]`는 `4-1=3`개이며, 같은 행의 여러 점도 그대로 센다.

기존 풀이는 시간 `O((N+Q) log(N+Q))`·공간 `O(N+Q)`다. 이분 탐색 방식은 시간 `O(N log N + Q log N)`, 좌표 저장 공간 `O(N)`이며 출력을 모으면 별도 `O(Q)`가 필요하다. 기존 제출의 공식 실행 결과는 1117 ms·462548 KiB다. 개선안을 같은 최대 입력·같은 PyPy에서 측정하지 않았으므로 구체적인 개선 비율은 미측정이다.

### D: 작은 N의 별도 처리에서 생긴 오류

WA·AC 버전을 비교하면 일반 부분은 같고 다음 두 곳을 고쳤다. 공식 숨은 입력 자체는 확인하지 못했지만, 두 오류 모두 작은 입력에서 재현했다.

| 입력 | 기대 출력 | WA 버전 | AC 버전 |
| --- | --- | --- | --- |
| `N=2, X=[0,2]` | `1,1`의 2줄 | `1` 한 줄만 출력 | `1,1` |
| `N=3, X=[0,2,4]` | `2,2,2` | `4,4,4` | `2,2,2` |

정리할 부분은 `N=2,3,4`와 끝 근처의 처리를 일반식으로 합치는 것이다. [공식 D 해설](https://atcoder.jp/contests/abc482/editorial/28014)은 처음 왼쪽 이웃을 감염시키는 경우와 오른쪽 이웃을 감염시키는 경우를 비교한다. 0-based 시작 위치 `i`에서 존재하는 후보만 계산한다.

```text
왼쪽 이웃이 있음: max(X[i]-X[0], X[-1]-X[i-1]) // 2
오른쪽 이웃이 있음: max(X[i+1]-X[0], X[-1]-X[i]) // 2
답: 존재하는 후보의 최솟값. N=1만 0으로 처리.
```

첫 감염 이후 두 좀비를 좌우로 보내고 인간은 좀비 쪽으로 이동시킬 수 있다. 마지막으로 감염되는 좌우 끝의 시간을 비교하면 위 식이 된다. 사용자 코드의 만나는 시간·위치 계산을 이 식으로 정리하면 중복 계산과 별도 분기를 줄일 수 있다. 제출 코드는 수정하지 않았다.

### E: DFS 접근과 중심을 이용한 단순화

사용자는 DFS로 분기별 최장 거리와 온 방향의 거리를 결합하려 했다고 보고했다. 유효한 접근이지만 거리뿐 아니라 같은 색의 끝점 개수와 서로 다른 분기인지도 관리해야 한다. 당시 미완성 DFS 코드는 확인하지 못했으므로 구체적인 구현 오류나 실패 원인을 단정하지 않는다.

중심을 고정하면 부모 방향으로 정보를 전달하는 부분을 줄일 수 있다. BFS 두 번으로 지름의 양 끝을 구하고 부모 배열로 지름 경로를 복원한다. 지름 길이를 `D`라고 하면 다음과 같다. [공식 E 해설](https://atcoder.jp/contests/abc482/editorial/28018).

- `D=2r`: 중심은 한 정점이다. 중심에서 깊이 `r`인 정점들을 분기별·색별로 센다. 같은 색이면서 서로 다른 분기에서 고른 쌍만 더한다.
- `D=2r+1`: 중심은 한 간선이다. 이 간선을 끊은 양쪽에서 각 중심까지 거리 `r`인 정점들을 색별로 센다. 같은 색의 왼쪽 개수×오른쪽 개수를 합한다.

짝수 지름에서 어떤 색의 개수가 분기별로 `2,1,3`이면 답은 `2*1+(2+1)*3=11`쌍이다. `seen[color]`는 이미 처리한 **다른 분기**의 개수다. 현재 분기의 `cnt`에 대해 `ans += seen[color]*cnt`를 계산한 뒤 합친다. 같은 분기를 조사하면서 정점을 하나씩 `seen`에 넣으면 같은 분기의 쌍까지 셀 수 있다.

현재 로컬 구현은 참고 코드를 바탕으로 작성했다는 사용자 확인이 있다. 참고 출처·작성 시점은 미확인이다. 확인한 버전의 SHA-256 앞부분은 `83f446a071cc`다. 중심 정점·중심 간선 처리가 이미 구현되어 있으며 에이전트는 변경하지 않았다. 참고 코드 기반의 일반 연습으로 기록하며 독립 발견·독립 재현과 구분한다.

### F·G: 업솔빙 후보

- **F는 E 다음의 도전 후보로 추천한다.** 나머지를 정점으로 하는 그래프와 약수를 곱하는 단계의 상태 표현을 다룬다. 최근 연습한 상태 그래프·0-1 BFS와 연결할 수 있다. [공식 F 해설](https://atcoder.jp/contests/abc482/editorial/28017)은 소인수별 단계를 나눠 `O(sqrt(N)+M log N)`에 해결한다. 모든 나머지에 모든 약수를 곱하는 방식은 느리다. 공식 해설에 PyPy의 상수 시간 비용에 관한 주의가 있으므로 구현 시 실제 실행 시간·메모리를 확인한다. 이번에 완성 코드를 제공하지 않았고 사용자 구현·AC는 미확인이다.
- **G는 이번에는 보류를 추천한다.** 일반 그래프의 차수 제한 문제이며, 기존 이분 매칭·최대 유량을 그대로 적용할 수 있는 조건이 아니다. [공식 G 해설](https://atcoder.jp/contests/abc482/editorial/27996)은 선형 마트로이드 패리티와 난수를 사용한 행렬 rank 계산을 다룬다. 필요한 새 지식이 많으므로 이번에는 C·D의 단순화와 E의 이해를 우선한다.

## 업솔빙과 검증 결과

2026-11-02에 에이전트가 Linux/WSL·CPython 3.12.14로 실행했다. 공식 제출 코드는 임시 영역에 받은 버전으로 실행했으며 사용자 풀이 파일은 수정하지 않았다. 공식 제출 언어 PyPy 3.11-v7.3.20과 로컬 실행 환경은 구분한다.

- A·B: 공식 예제 각각 3개 통과.
- C: 제출 코드로 공식 예제 2개 및 중복 좌표·양 끝 포함·빈 범위·큰 좌표 `10^9`를 포함한 6개 질의를 통과했다. 6개 질의는 점을 직접 열거해 기대값 `3,2,0,2,5,1`을 구했고 실제 출력과 일치했다. 단순화한 이분 탐색식도 공식 예제 2개와 같은 6개 질의에서 일치했다.
- D: AC 코드로 공식 예제 2개 통과. 위 `N=2,3` 입력에서 WA 코드의 오류와 AC 코드의 수정을 확인했다.
- E: 참고 기반 로컬 구현으로 공식 예제 3개 출력 `1,2,2`를 확인했다. 추가 5개는 2정점 동색 `1`·이색 `0`, 동색 5정점 경로 `1`·4정점 경로 `1`, 같은 분기의 끝점을 제외하는 7정점 트리 `4`다. 작은 트리의 모든 정점 쌍 거리를 BFS로 따로 계산해 기대값과 실제 출력의 일치를 확인했다.

마지막 7정점 트리는 간선 `1-2,2-3,2-4,1-5,5-6,5-7`, 색 `[2,3,1,1,4,1,1]`이다. 지름 4의 후보 `3,4,6,7` 중 같은 분기의 `(3,4),(6,7)`을 제외하면 4쌍이다.

**E의 온라인 AC는 미확인**이다. F·G는 미구현·미실행이며 별도 날짜의 독립 재현도 미확인이다. 로컬 통과를 종료 후 5/7 AC로 바꾸지 않는다.

## 다음 행동과 배운 점

다음 한 행동은 **E의 현재 참고 구현을 중심·분기별 색 집계와 연결해 검토하고 사용자가 온라인 제출해 판정을 확인하는 것**이다. C·D는 짧게 검토하고, AC된 모든 문제의 재구현을 다음 학습의 조건으로 삼지 않는다. 그다음 도전 후보는 F이며 G는 이번에 보류한다.

이번 복기의 공통 주제는 필요한 정보만 남기는 것이다. C는 정적 개수를 이분 탐색으로 직접 구하고, D는 여러 별도 처리를 첫 감염 상대의 두 후보로 합치며, E는 중심을 고정해 색별 쌍을 센다.

다음 대회에서 바꿀 행동은 두 가지다.

1. 구현 전에 데이터가 정적인지, 필요한 정보와 일반식이 무엇인지 짧게 확인한다.
2. 작은 입력의 별도 분기를 추가했다면 출력 줄 수도 포함해 실행한다.

미완료 주 학습인 [CSES Prefix Sum Queries](https://cses.fi/problemset/task/2166/)는 보존하며 이번 복기 후 T08로 돌아간다.
