# 대회 기록

대회 기록은 실제로 참가했거나 새 Div. 2 virtual을 수행한 회차만 `contests/<slug>.md`에 남긴다. 첫 두 회차는 실력의 기준점을 얻기 위한 기록이다.

## 최소 형식

대회 노트의 YAML 메타데이터에는 다음 필드를 둔다.

```yaml
---
title: "대회 제목"
updated: "YYYY-MM-DD"
tags:
  - "codeforces"
url: "https://codeforces.com/contest/..."
---
```

`url`은 해당 대회의 실제 원문 URL이다. 판정, 도움 여부, 재풀이 여부 같은 상태는 확인한 뒤 본문에 적고, 확인하지 않은 값은 `unknown`으로 남긴다. rating을 다른 체계로 환산하거나 자동 진도 데이터베이스를 만들지 않는다.

## 기록 순서

대회 전에는 실전인지 virtual인지와 제한 시간을 적는다. 대회 중에는 직접 시도한 문제와 제출 결과를 표시한다. 대회 후에는 3–4시간 업솔빙에서 막힌 원인, 해설을 본 시점, 다시 독립적으로 구현했는지를 문제별로 남긴다.

완료된 대회의 설명을 복사하지 않는다. 필요한 경우 자기 풀이와 배운 점을 적고, 문제 원문은 각 문제의 URL로 연결한다. 문제를 별도 노트로 남길 때는 [문제 노트 템플릿](../templates/problem-note.md)을 기존 `atcoder/`, `codeforces/` 또는 `leetcode/` 코드 옆에 동일한 basename으로 복사하고, 실제 `.py` 파일을 노트 기준 상대 경로로 연결한다.

`contests/template.md`는 복사해 쓰는 참고 템플릿이며 자동 기록이나 자동 검사 대상이 아니다.
