# 학습 회차와 운영 계약

이 계약은 [명세](../spec.md) FR-001–019를 회차 운영에 연결한다. 자연어 요청과 학습자에게 제시하는 과제의 약속이며 새 CLI·API를 개발하지 않는다. 후속 적용 위치는 ROADMAP과 기존 학습 스킬이다.

## 입력과 회차의 결과

| 입력 상황 | 반드시 제공할 결과 |
| --- | --- |
| `학습 시작`·`계속` | STATE와 현재 코드·노트·대화를 대조해 다음 과제 하나·선정 이유·완료 기준을 제시 |
| `DP/SCC/이분탐색을 하자` | 지정 주제와 현재 근거를 우선하고 해당 과제에 필요한 선수만 보완 |
| 처음 배우는 기법 | 목적·원리·작은 예제·적용 조건 설명 뒤 직접 설계·백지 구현·실행·반례 검토 |
| 익숙한 주제·혼합 연습 | 기존 근거를 재시험하지 않고 독립 시도. 접근 선택 측정에는 태그·기법·해설을 사전 공개하지 않음 |
| `힌트 줘` | 실제 코드·설명·막힌 위치를 확인하고 필요한 최소 도움 뒤 전체 과제로 복귀 |
| `오늘 학습 종료` | 확인한 결과·남은 질문·다음 행동을 짧게 보고. 저장은 [기록 계약](document-records.md)에 따름 |

기본 회차는 한 줄 퀴즈의 연속이 아니라 설계 → 직접 구현 → 실제 실행 → 코드 기반 리뷰의 충분한 작업이다. 입력/출력 준비만 요청받으면 알고리즘 본문을 채우지 않는다. 코드 제공·수정을 요청받은 범위는 수행할 수 있으며 도움을 구분한다.

## 현재 재개와 문제 선택

1. 현재 `find_scc`·`build_condensation`과 비어 있는 `max_coins`를 읽고 남은 SCC별 값 집계·DAG DP 설계로 이어간다. 기존 SCC의 입문 강의·재구현을 재개 관문으로 만들지 않는다.
2. scratch가 없으면 공유 가능한 기존 SCC 코드와 마지막 확인 근거에서 남은 범위를 확인한다. scratch가 있다고 가정하거나 사용자 코드를 새 템플릿으로 덮지 않는다.
3. ABC A–E 경험을 바탕으로 F/G 또는 적정 새 문제에서 선택·증명·구현·시간 배분을 관찰한다. F/G 문자만으로 난도를 고정하거나 미시도·독립성을 추정하지 않는다.
4. 미견 측정을 고를 때 현재 후보의 노출만 짧게 확인한다. 이미 본 문제면 재풀이/일반 연습으로 구분하거나 다른 후보를 고른다. 과거 전체 풀이 이력을 답해야 시작할 수 있게 하지 않는다.

## 주제별 진입과 다음 선택

이 계획의 범위와 선택 심화는 [승인 명세의 T01–T13 지도](../spec.md#유한한-주제-지도)를 따른다. 개편 적용 후 실제 학습 범위와 운영은 [ROADMAP](../../../ROADMAP.md)을 기준으로 한다. 아래는 후속 반영을 위해 각 주제에서 과제를 고를 때 관찰할 기준을 정리한 설계다. 현재 학습 완료 기록이나 각 행을 한 번에 수행할 숙제 목록이 아니다.

| 주제 | 필요한 선수·진입점 | 표준 과제에서 볼 근거 | 다음 변형·재방문 계기 |
| --- | --- | --- | --- |
| T01 탐색·배열·순서 | 복잡도·인덱스·단조성 중 필요한 부분 | 탐색 구간·누적값·투포인터 불변식 또는 결정 조건과 경계 실행 | 결정 문제 모델링·경계 방향을 바꾼 변형; 단조성 판단 오류 시 보완 |
| T02 완전탐색·구현 | 상태·열거 범위 | 작은 완전탐색의 누락/중복·복원·시뮬레이션 순서 | 가지치기·반분/비트마스크 등 필요한 변형; 상태 일관성 오류 시 재방문 |
| T03 그리디·정당성 | 정렬·반례 만들기 | 선택 이유·교환 논증/불변식과 반례 검토 | 조건을 바꾼 구성·일정 문제; 근거 없는 국소 선택이 반복되면 보완 |
| T04 DP | 상태 모델링, DAG/트리 등 현재 전이에 필요한 구조 | 상태 의미·초기값·전이 누락/중복·계산 순서 | 배낭·구간·트리·비트 등 다른 상태의 변형; 전이 설명 공백 시 재방문 |
| T05 그래프 구조 | 현재 과제의 탐색·종료 순서·위상 조건 | 현재 SCC/축약 구현에서 이어 DAG 연결·고립/중복 간선 검토 | 함수형 그래프·2-SAT 등 해당 응용; SCC를 전부 재강의하지 않음 |
| T06 경로·연결 비용 | 가중치 조건·그래프; MST에는 DSU | 알고리즘 선택의 성립 조건·복원·도달 불가 처리 | 가중치·상태·경로 요구가 바뀐 문제; 음수 간선 조건 혼동 시 보완 |
| T07 매칭·유량 | 그래프 모델링·증가 경로, 해당 잔여 그래프 | 매칭/유량 보존·역간선·컷의 의미와 실제 구현 | 최소 컷 모델링·비용 조건을 추가하는 응용; 잔여 상태 오류 시 재방문 |
| T08 자료구조·트리 | 결합·인덱스, 해당 트리 순회 | 현재 sum/min 근거를 재사용해 질의/갱신·경계·복잡도 확인 | 순위 탐색·lazy·LCA/HLD 등 필요한 갈래; 보류된 리프 배치 질문과 연결 |
| T09 문자열 | 배열·접두/접미 관계, 해싱에는 충돌 개념 | 불일치 이동/일치 상태의 의미·경계·계산량 | 패턴/접미사 조건이 다른 변형; 해싱을 확정적 동일성으로 다루면 보완 |
| T10 수학·확률·게임 | 해당 정수·조합·확률·DP 전제 | 수식의 성립 조건·모듈러 나눗셈/게임 상태·작은 값 비교 | 수론·조합·기댓값·Grundy 중 필요한 갈래; 전제 누락 시 보완 |
| T11 기하 | 벡터·외적·정렬·오차 | 방향/교차 판정·일직선/중복점 등 퇴화 조건 | 볼록 껍질·거리/면적 응용; 부호·퇴화 오류에 맞춰 재방문 |
| T12 오프라인·분할정복·최적화 | 선택한 갈래의 정렬·DP·구간질의 | 재정렬 가능성·이벤트 순서·복잡도, 최적화의 성립 조건 | Mo·CDQ·CHT 등 관찰한 필요에 맞춰 선택; 조건 증명이 비면 보완 |
| T13 다항식·합성곱 | 직접 다항식 곱·분할정복; FFT/NTT별 수학 | 작은 직접 곱과 결과 비교·길이/정규화·오차/모듈러 조건 | FFT/NTT 적용과 후속 응용; 유량 등 무관한 갈래 완주를 요구하지 않음 |

## 상향·보완·이동·재방문

- **상향**: 서로 다른 대표 변형 두 개의 설계·직접 구현·경계 실행·적용 조건·복잡도 설명을 확인한다. 추가 핵심 힌트가 필요했던 변형은 도움을 분리하고 별도 변형으로 근거를 보완한다. 이미 충분한 실제 증거가 있으면 다시 시험하지 않는다.
- **보완**: 핵심 단계 둘 이상을 새로 배워야 하거나 같은 공백이 두 시도에서 반복되면 그 선수·단순 변형을 제안한다. 사용자가 새 접근을 탐색 중이면 계속 시도할 수 있다.
- **이동**: 해당 과제의 설명·구현·경계 검토가 가능하고 다음 주제의 선수가 준비되면 이동할 수 있다. 해당 주제의 선택 심화 완주를 요구하지 않는다.
- **재방문**: 미완료 심화와 남은 질문을 구분하고, 다른 날 자료 없는 재현·새 문제 적용·다음 갈래의 필요에서 하나를 고른다. 두 변형의 잠정 상향을 장기 숙달로 부르지 않는다.

힌트는 관찰/반례 → 필요한 부분 설명 → 핵심 아이디어 → 요청 시 해설·코드 중 막힘에 맞는 범위만 사용한다. 시계는 배분 점검 도구이며 정답을 자동 공개하는 조건이 아니다.

## 여섯 주간 예산

모든 칸은 전체 활동 시간이며 단위는 분이다. 설명·복기·기록이 합계 안에 포함된다. 대회 주 표는 공식 100분 ABC를 선택한 경우다.

| 유형 | 가용 시간 | 주제 학습 | 혼합 문제 | 대회 | 복기·업솔빙 | 다른 날 재현·반례 | 기록·다음 범위 | 합계 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 일반 | 5시간 | 150 | 60 | 0 | 0 | 60 | 30 | 300 |
| 일반 | 6시간 | 180 | 90 | 0 | 0 | 60 | 30 | 360 |
| 일반 | 7시간 | 210 | 90 | 0 | 0 | 90 | 30 | 420 |
| ABC 대회 | 5시간 | 90 | 0 | 100 | 50 | 40 | 20 | 300 |
| ABC 대회 | 6시간 | 120 | 0 | 100 | 80 | 40 | 20 | 360 |
| ABC 대회 | 7시간 | 150 | 0 | 100 | 80 | 70 | 20 | 420 |

일반 주의 주제·혼합 활동에는 해당 리뷰를 포함한다. 그 전체를 독립 시간으로 세지 않는다. 아래는 위 활동 안에 확보하는 독립 설계·구현·실행·반례 검토의 최소 배정 예시다. 활동 시간과 별도로 더하는 시간이 아니다.

| 유형·시간 | 주제 안 | 혼합 안 | 대회 안 | 복기·업솔빙 안 | 재현·반례 안 | 독립 합계 | 전체의 절반 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 일반 5시간 | 90 | 45 | 0 | 0 | 40 | 175 | 150 |
| 일반 6시간 | 110 | 70 | 0 | 0 | 40 | 220 | 180 |
| 일반 7시간 | 130 | 70 | 0 | 0 | 60 | 260 | 210 |
| ABC 대회 5시간 | 50 | 0 | 100 | 20 | 25 | 195 | 150 |
| ABC 대회 6시간 | 70 | 0 | 100 | 40 | 25 | 235 | 180 |
| ABC 대회 7시간 | 90 | 0 | 100 | 40 | 45 | 275 | 210 |

각 활동의 설명·상담·AI 작업 시간은 독립 시간에 넣지 않는다. 계획한 독립 시간은 실제 수행 시간이나 도움 없이 해결했다는 증거가 아니다. 실제 배분이 달라지면 시간과 도움 범위를 따로 확인하고 다음 활동을 조정한다.

대회 길이가 다르면 해당 공식 시간을 넣고 다른 활동을 줄여 전체 예산과 독립 작업 절반을 다시 확인한다. 주제 학습과 100분 대회를 매주 둘 다 의무화하지 않는다. 5시간 미만인 예외 주에는 핵심 과제 하나 또는 휴식을 선택하고 실제 시간을 남긴다.

## 첫 4주와 이월

| 주 | 기본 선택 | 다음 주 조정 |
| --- | --- | --- |
| 1주 | 현재 SCC에서 값 집계·DAG DP 연결 | 미완료면 2주의 신규 DP 범위를 줄이고 연결 작업 유지 |
| 2주 | 실제 공백에 맞는 DP 응용·대표 변형 | 측정 대회를 선택하면 주간 활동을 대체. 미완료를 숙제로 누적하지 않음 |
| 3주 | 이분탐색의 단조성·경계·결정 문제 응용 | 이전 작업의 지연 재현을 기존 재현 시간 안에 배치 |
| 4주 | 태그 없는 혼합 적용·운영 검토 | 실제 시간·도움·반복 오류·재현으로 유지/축소/상향 중 하나 선택 |

2주에 한 번 실전 또는 미견 virtual을 선택할 기회를 기본으로 하되 일정·예산에 따라 일반 주로 운영할 수 있다. 첫 4주에는 최소 한 번 측정할 기회를 두며 불참·미실행은 그대로 둔다. 적용 후 실제 첫 학습일부터 계산하고 rating·올솔을 4주 성과로 보장하지 않는다. 이후에도 4주 단위로 재조정한다.

## 대회와 측정 경계

실전·측정용 virtual 진행 중에는 AI 풀이·디버깅을 제공하지 않고 종료 후 복기로 이어간다. 도움을 받은 virtual은 일반 연습으로 구분한다. 이미 본 세트는 기출 재풀이이며 미견 측정으로 합산하지 않는다. 목표별 결과와 판정 출처는 [기록 계약](document-records.md)을 따른다.
