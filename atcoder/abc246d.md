# ABC246 D - 2-variable Function

## 핵심 요약

비음수 정수 `a, b`에 대해 `a^3 + a^2 b + ab^2 + b^3`으로 표현되면서 `N` 이상인 최소 값을 찾는다. 사용자가 식을 `(a + b)(a^2 + b^2)`로 인수분해했다. 현재 풀이는 `a`를 열거하고 `b`를 이분 탐색한다.

## 접근과 범위

`a`를 고정하면 식은 `b`에 대해 증가하므로, 값이 `N` 이상인 최소 `b`를 구한다. `(a + b)`만 같아도 식의 값은 달라서 합 하나만 탐색하지는 않는다.

`N <= 10^18`이고 `(a, b) = (0, 10^6)`이 값 `10^18`을 만든다. 각 변수의 세제곱도 식에 포함되므로 이 후보보다 좋은 답을 찾을 때는 `0..10^6` 범위로 충분하다. 현재 `range(10**6)`은 `a = 10^6`을 제외하지만, 그 경계에서 필요한 `(10^6, 0)`은 대칭인 `(0, 10^6)`으로 포함된다.

`U = 10^6`일 때 시간은 `O(U log U)`, 추가 공간은 `O(1)`이다. 이분 탐색은 아래쪽 중간값을 쓰고 조건을 만족하면 `hi = b`로 줄인다. 탐색 후에는 `b`가 아니라 식의 값을 반환한다.

## 실패와 도움

사용자의 인수분해 관찰에서 시작해 열거 범위와 단조성을 설명했다. 위쪽 중간값과 `hi = b`를 함께 써 탐색이 멈추지 않는 문제, 반환 대상이 다른 문제를 교정했다. 에이전트가 계산식을 인수분해 형태로 정리하고 `a*a`의 중복 계산을 줄였다. 실행 시간은 로컬 환경에 의존하며 저지 제한 통과를 보장하는 근거로 쓰지 않는다.
