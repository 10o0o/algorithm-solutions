# ABC212 D - Querying Multiset

## 핵심 요약

값 추가, 현재 있는 모든 원소에 덧셈, 최솟값 꺼내기를 처리한다. 현재 풀이는 최소 힙과 전체 누적 가산값 `add`를 분리하여 모든 원소를 매번 다시 쓰지 않는다.

## 접근과 불변식

항상 `실제 값 = 힙의 저장값 + add`를 유지한다. 전체 가산은 `add`만 바꾸고, 실제 값 `x`를 새로 넣을 때는 `x - add`를 저장한다. 최솟값을 꺼낼 때 저장값에 현재 `add`를 더한다.

모든 저장값에 같은 `add`를 더해도 대소관계는 변하지 않아 힙을 다시 만들 필요가 없다. 새로 들어오는 공에는 과거 덧셈이 적용되면 안 되므로 삽입 때 보정해야 한다. 저장값이 음수가 되어도 실제 값과 힙 순서는 올바르다. 전체 시간은 `O(Q log Q)`, 입력 쿼리와 답을 포함한 공간은 `O(Q)`이다.

## 실패와 도움

사용자가 힙과 누적 가산값을 두는 접근을 구현했다. 새 원소를 그대로 넣어 이전 가산까지 적용되는 오류가 있었고, 에이전트가 불변식을 설명하고 삽입을 `x - add`로 한 줄 수정했다. 전체 모범 코드를 제공한 사례와 구분하며, 온라인 AC 보고는 미확인이다.

## 반례

```text
5
1 5
2 3
1 2
3
3
```

기대 출력과 현재 실제 출력은 다음과 같다.

```text
2
8
```

이전 구현은 `5, 8`을 출력했다. `add = 3`일 때 새 값 2는 저장값 -1로 표현해야 한다.
