# ABC233 D - Count Interval

## 핵심 요약

음수가 포함될 수 있는 배열에서 합이 `K`인 비어 있지 않은 연속 구간의 개수를 구한다. 누적합의 차이를 이용해 현재 누적합보다 `K`만큼 작은 과거 누적합의 개수를 더한다.

## 접근과 불변식

`P[r] - P[l] = K`이려면 `P[l] = P[r] - K`이다. `counts`에는 현재 위치보다 앞선 누적합들의 출현 횟수를 둔다. 초기 누적합 0을 한 번 넣으면 첫 원소부터 시작하는 구간도 센다.

현재 누적합 `acc`를 만든 후 `counts[acc - K]`를 답에 더하고, 그 다음 `counts[acc]`를 증가시킨다. 현재 누적합을 먼저 등록하면 `K = 0`일 때 빈 구간을 셀 수 있다. 음수 때문에 구간 길이와 합의 단조성을 가정하지 않는다.

해시 맵의 평균적인 연산 비용을 기준으로 시간은 `O(N)`, 공간은 `O(N)`이다. 같은 누적합도 여러 번 나올 수 있어 집합이 아니라 빈도표를 쓴다.

## 도움과 구현

사용자가 접근을 찾기 어렵다고 하여 누적합 차이 식과 빈도표, 조회 후 등록 순서를 설명했다. 그 후 사용자가 현재 코드를 구현했고, 에이전트 검증에서 추가 수정은 필요하지 않았다. 이는 설명 후 구현이며 무힌트 접근 선택으로 기록하지 않는다.

## 확인한 입력

```text
3 0
0 0 0
```

비어 있지 않은 모든 구간이 정답이므로 기대 출력과 실제 출력은 `6`이다.
