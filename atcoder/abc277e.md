# ABC277 E - Crystal Switches

## 핵심 요약

무방향 간선의 초기 통행 여부가 주어지고, 일부 정점에서는 모든 간선의 통행 여부를 반전할 수 있다. 이동 횟수만 최소화하므로 이동 비용은 1, 스위치를 누르는 비용은 0이다. 정점과 전체 반전 여부를 상태로 하는 0-1 BFS를 쓴다.

## 접근과 불변식

`dists[v][mode]`는 정점 `v`에 반전 홀짝이 `mode`인 상태로 도착하는 최소 이동 횟수다. 시작 상태 `[1][0]`만 0으로 초기화한다. `mode = 0`에서는 `a = 1`, `mode = 1`에서는 `a = 0`인 간선을 사용할 수 있다.

- 스위치가 있는 정점에서는 위치를 유지한 채 반전 상태를 바꾼다. 비용 0이므로 덱 앞에 넣는다.
- 통행 가능한 간선으로 이동할 때는 거리에 1을 더하고 덱 뒤에 넣는다.
- 더 짧은 거리일 때만 등록하고 오래된 후보는 버린다. 이 조건은 무료 전환을 반복해도 끝나게 한다.

비용 d인 후보에서 무료 후보는 d, 이동 후보는 d+1이다. 앞뒤 배치로 작은 비용부터 처리하며 시간과 공간은 각각 `O(N + M)`이다. 목표의 두 상태가 모두 무한대면 `-1`이다.

## 실패와 도움

에이전트가 0-1 BFS의 앞뒤 삽입 원리를 설명하고 사용자가 구현했다. 이동 거리를 도착 정점 `v` 대신 출발 정점 `node`에 갱신했고, 무방향 간선의 반대 방향과 시작 거리 초기화, 도달 불가의 `-1` 처리가 빠졌다. 에이전트가 이 네 부분을 수정했다. 무료 전환의 앞쪽 삽입과 통행 조건은 처음 구현부터 맞았다.

## 확인한 입력

```text
2 1 0
2 1 1
```

무방향이므로 기대 출력과 현재 실제 출력은 `1`이다. 추가로 `1 2 0` 간선만 있고 스위치가 없으면 기대값은 `-1`이다.
