# Typical 90 001 - Yokan Party

## 핵심 요약

길이 `L`인 양갱을 주어진 위치 중 `K`곳에서 잘라, `K + 1`조각의 최소 길이를 최대화한다. 최소 길이 후보를 정한 뒤, 그 길이 이상의 조각을 충분히 만들 수 있는지 그리디로 판정한다.

## 접근과 불변식

`can(x)`는 길이 `x` 이상인 조각을 `K + 1`개 이상 확보할 수 있는지 검사한다. 직전 경계에서 `x` 이상 떨어진 가장 이른 절단점을 고르면 남은 부분을 가장 길게 유지할 수 있다. 남는 조각은 합칠 수 있으므로 정확히 `K`번 자르는 조건에도 맞출 수 있다.

가능한 길이가 `x`라면 더 작은 길이도 가능하다. 최대 참을 찾는 현재 이분 탐색은 위쪽 중간값 `(lo + hi + 1) // 2`를 사용한다. 참이면 `lo = mid`, 거짓이면 `hi = mid - 1`로 갱신한다. 특히 `hi = lo + 1`일 때도 구간이 줄어든다.

현재 구현은 `cuts + [L]`로 마지막 조각까지 판정한다. 시간은 `O(N log L)`, 입력과 판정 중 만드는 리스트를 포함한 공간은 `O(N)`이다.

## 실패와 도움

사용자 구현에서 절단 위치와 조각 길이의 혼동, `>`와 `>=`, 조각 개수와 마지막 구간 처리를 함께 검토했다. 사용자가 판정을 수정했고, 에이전트가 마지막 끝점 `L`을 순회에 넣는 부분을 수정했다. 이분 탐색의 `+1`이 무한 반복을 막는 이유도 설명했다. 모범 코드 전체를 제공한 문제와는 구분한다.

## 확인한 입력

```text
1 10
1
5
```

기대 출력과 현재 실제 출력은 `5`다. 마지막 `[5, 10]` 구간도 한 조각으로 세어야 한다.
