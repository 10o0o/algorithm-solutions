# AtCoder DP F - LCS

## 핵심 요약

두 문자열의 최장 공통 부분 수열 하나를 출력한다. 현재 코드는 접두사별 LCS 길이를 2차원 DP에 저장한 뒤, 오른쪽 아래에서 역추적하여 문자열을 복원한다.

## 접근과 불변식

`dp[i][j]`는 `s[:i]`와 `t[:j]`의 LCS 길이다. 빈 접두사에 대한 값은 0이다.

- 마지막 문자가 같으면 `dp[i - 1][j - 1] + 1`이다.
- 다르면 `max(dp[i - 1][j], dp[i][j - 1])`이다.
- 역추적 중 문자가 같으면 답에 넣고 대각선으로 이동한다. 다르면 길이를 유지하는 위쪽이나 왼쪽으로 이동한다.

답은 뒤에서부터 모으므로 마지막에 뒤집는다. `previous`와 `current`는 DP 행을 가리키는 참조이며 별도의 복사본이 아니다. 길이를 계산하고 문자열을 복원하는 데 시간과 공간은 각각 `O(nm)`이다.

## 실패와 도움

사용자 구현에서 문자열의 `max()`를 길이 비교로 사용한 점, 인덱스, 1차원 갱신에서 이전 행의 대각선 값을 잃는 점을 설명했다. 이후 사용자가 모범 코드를 요청하여 에이전트가 현재의 길이 DP와 역추적 구현을 제공했다. 행 참조와 역추적 흐름을 추가로 설명했으며, 사용자는 이해했다고 답했다. 이 사실을 백지 구현이나 독립 해결로 해석하지 않는다.

## 확인한 입력

```text
abc
adc
```

기대 출력과 현재 실제 출력은 `ac`다. 마지막 `c`와 첫 `a`를 역순으로 모은 뒤 뒤집는다.
