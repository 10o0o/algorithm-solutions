# 2226. Maximum Candies Allocated to K Children

## 핵심 요약

각 아이에게 같은 양 x를 줄 수 있는지 판단하면, 가능한 x의 범위가 앞쪽에 모이는 단조 판정이 된다. 저장된 구현은 sum(candy // x) >= k라는 floor-sum predicate를 이분 탐색해 가능한 x의 최댓값을 찾는다.

$$
\operatorname{can}(x) \iff \sum_i \left\lfloor \frac{c_i}{x} \right\rfloor \ge k, \quad x \ge 1
$$

## 문제에서 확인한 조건

- 각 candy pile은 나누어 여러 아이에게 줄 수 있고, 한 아이에게 주는 양은 모두 같아야 한다.
- 서로 다른 pile을 합쳐 하나의 pile처럼 만들 수 없고, 한 아이는 한 pile에서 받은 candy만 사용한다. 따라서 각 pile이 만들 수 있는 아이 수를 따로 계산해 더한다.
- 한 pile에서 x개씩 줄 수 있는 아이 수는 candy // x이다.
- x가 클수록 만들 수 있는 아이 수는 줄어들거나 같으므로 feasibility가 단조다.
- 모든 아이에게 양의 candy를 줄 수 없으면 답 0이다.

## 접근과 불변식

can_divide(value)는 모든 pile에 대해 candy // value를 더한 값이 k 이상인지 확인한다. 이 값은 value가 커질수록 증가하지 않으므로 가능한 후보는 작은 값에서부터 답까지의 접두 구간이다.

저장된 구현의 경계는 left = 0, right = max(candies)다. 반복마다 upper-mid를 사용한다.

- value가 가능하면 답이 더 클 수 있으므로 left = mid로 올린다.
- value가 불가능하면 mid 이상은 모두 불가능하므로 right = mid - 1로 내린다.

left는 항상 가능한 경계이고 right보다 큰 값은 답이 될 수 없다는 불변식이 반복마다 유지된다. left < right인 동안 right >= 1이므로 mid = (left + right + 1) // 2도 1 이상이다. 따라서 현재 코드의 can_divide는 0으로 나누지 않는다. 마지막에 left == right가 되면 가능한 최댓값이다.

## 풀이와 복잡도

현재 코드는 pile을 한 번 순회해 feasibility를 판정하고, 0부터 최대 pile 크기까지의 정수 답 공간을 절반씩 줄인다. n을 pile 수, M을 최대 pile 크기라 하면 시간은 $O(n\log(M+1))$, 추가 공간은 $O(1)$이다. 저장된 구현에는 별도 배열이나 memoization이 없다.

## Python 주의점

- upper-mid를 사용해야 left와 right가 한 칸 차이일 때도 경계가 진행된다.
- can_divide에 value = 0을 넘기면 ZeroDivisionError가 난다. 현재 저장된 경계 구조는 반복 중 mid가 0이 되지 않는 것을 전제로 한다.
- max(candies)는 입력이 비어 있으면 실패한다. 이는 원문 입력 조건 밖의 일반화이며, 입력 조건을 바꾸면 빈 배열을 먼저 처리한다.
- Python 정수는 overflow가 없지만, 다른 언어의 큰 합·mid 계산에서는 자료형과 중간값 계산식을 확인한다.

## 경계와 함정

- total candies가 k보다 작으면 어떤 양의 x도 k명을 만들 수 없으므로 0이 반환된다.
- 최대 pile만 보고 답을 정하면 안 된다. 여러 pile의 몫 합이 k 이상인지 판정해야 한다.
- x = 0을 “항상 가능”한 경계로 사용할 수는 있지만 실제 candy // x 계산에는 넣지 않는다.
- mid = (left + right) // 2만 사용하면 upper bound를 찾는 반복이 멈추지 않을 수 있다.
