# 1422. Maximum Score After Splitting a String

## 핵심 요약

이진 문자열을 두 비어 있지 않은 부분으로 나눌 때 왼쪽의 0 개수와 오른쪽의 1 개수의 합을 최대로 한다. 저장된 구현은 오른쪽 1 개수를 한 번 세고, 분할점을 오른쪽으로 한 칸씩 옮기며 양쪽의 개수를 갱신한다.

$$
\operatorname{score}(i) = L_i + R_i
$$

$L_i$는 앞의 i개 문자에 있는 `0` 개수, $R_i$는 나머지 문자에 있는 `1` 개수다.

## 문제에서 확인한 조건

- 입력은 0과 1로 이루어진 문자열이다.
- split은 양쪽이 비어 있지 않도록 첫 문자와 마지막 문자 사이에서만 선택한다.
- 점수는 왼쪽 부분의 0 개수 + 오른쪽 부분의 1 개수다.
- 저장된 구현은 문자열 전체를 입력으로 받고 LeetCode의 Solution class API를 유지한다.

## 접근과 불변식

처음에는 right_ones에 문자열 전체의 1 개수를 둔다. 반복에서 현재 문자를 split의 왼쪽으로 옮긴다고 생각한다.

- 현재 문자가 0이면 left_zeros를 1 늘린다.
- 현재 문자가 1이면 아직 오른쪽에 있던 1 하나가 빠지므로 right_ones를 1 줄인다.
- 그 직후 left_zeros + right_ones가 현재 split의 정확한 점수다.

반복 범위를 s[:-1]로 제한해 마지막 문자를 왼쪽으로 옮기는 단계는 제외하고 오른쪽이 비지 않게 한다. 따라서 가능한 split을 정확히 한 번씩 평가하고, ans에는 지금까지 본 점수의 최댓값이 남는다.

이 방법은 prefix 배열 전체를 만들지 않는다. 현재 split에 필요한 왼쪽 0 count와 오른쪽 1 count만 유지하는 rolling aggregate이며, 문제를 prefix-sum array를 만드는 구현으로 설명하면 저장된 코드와 다르다.

## 풀이와 복잡도

현재 코드는 다음 순서로 동작한다.

1. right_ones = s.count("1")로 오른쪽 1 개수를 한 번 준비한다.
2. s[:-1]의 각 문자를 왼쪽으로 이동하며 count를 갱신한다.
3. 매 위치의 점수를 ans와 비교해 최댓값을 반환한다.

count 계산과 한 번의 순회로 시간은 $O(n)$이다. 다만 Python의 s[:-1]은 새 문자열을 만들므로, 현재 저장된 구현의 추가 공간은 $O(n)$이다. count 상태 자체와 인덱스 기반 순회 변형의 추가 공간은 $O(1)$이다. 원본 풀이 파일은 이 설명을 위해 변경하지 않았다.

## Python 주의점

- s[:-1]은 마지막 문자를 제외한 새 문자열을 만든다. 메모리까지 엄밀하게 평가할 때 이 복사를 빠뜨리지 않는다.
- 문자열은 불변이므로 문자를 왼쪽으로 실제 이동시키는 것이 아니라 count만 갱신한다.
- 입력이 이진 문자열이라는 조건 아래에서 else를 1 처리해도 된다. 다른 문자가 들어오는 일반화에서는 명시적인 검사를 추가한다.

## 경계와 함정

- 길이 2인 "00"과 "11"은 split이 하나뿐이며 답은 각각 1이다.
- "011101"에서는 첫 split 뒤 점수가 1 + 4 = 5이고, 가능한 split 중 최댓값도 5다.
- 마지막 문자를 반복에 포함하면 오른쪽이 빈 문자열이 되는 잘못된 split을 평가한다.
- 매 split마다 전체 왼쪽·오른쪽을 다시 세면 $O(n^2)$이 되므로, 한 문자가 어느 쪽으로 이동하는지만 갱신한다.
